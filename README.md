# Jinxiao (Johnny) Zhou — Portfolio

Welcome! 👋

This repository hosts my personal portfolio site — a small, hand-built corner of the web where I keep my background, projects and résumé in one place. No frameworks, no build step, no trackers.

### 👉 [**Visit the site →**](https://jinxiaozhou.github.io)

---

## What's inside

- **Bilingual** — English by default, with a 中文 switch in the header. The résumé download follows the language you pick.
- **Light & dark themes** — picked up from your system preference, and you can toggle it yourself.
- **Responsive** — designed mobile-first, from 320px up.
- **Accessible** — semantic markup, keyboard navigable, WCAG 2.2 AA contrast, respects reduced-motion.
- **No dependencies** — just HTML, CSS and vanilla JavaScript.

## Sections

About · Education · Experience · Projects · Skills · Beyond the code · Contact

## Running it locally

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Layout

```
index.html                        page content (English inlined for SEO)
assets/css/style.css              design tokens and components
assets/js/i18n.js                 Chinese dictionary
assets/js/main.js                 language, theme, navigation, scroll
assets/resume/                    résumé PDFs, one per language
publish_resume.py                 résumé publishing helper
```
